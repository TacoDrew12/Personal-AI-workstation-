# Personal AI Workbench Skill

A standalone Agent Skill for planning, building, polishing, testing, and delivering beginner-friendly personal dashboards and digital workspaces.

## Install or use

Give your AI agent the file:

`skills/personal-ai-workbench/SKILL.md`

Or install the `skills/personal-ai-workbench/` folder using the skill workflow supported by your AI agent.

Example instruction:

> Use the `personal-ai-workbench` skill to build me a personal study dashboard. Start with a useful first version, protect my data, and make it work well on mobile.

## Repository structure

```text
personal-ai-workbench/
├── README.md
└── skills/
    └── personal-ai-workbench/
        └── SKILL.md
```

## Publish on GitHub

1. Create a new GitHub repository named `personal-ai-workbench`.
2. Upload the contents of this folder, preserving the directory structure.
3. Commit the files to the default branch.
4. Share the repository URL with your AI agent.

The raw skill URL will follow this pattern:

```text
https://raw.githubusercontent.com/<GITHUB-USERNAME>/personal-ai-workbench/main/skills/personal-ai-workbench/SKILL.md
```

Replace `<GITHUB-USERNAME>` with your GitHub username.

This repository contains only the Personal AI Workbench skill. It is intentionally separate from any other skill repository.
